# Suporte e privacidade

## Onde pedir ajuda

Para bugs e problemas reproduzíveis, use o repositório do Daymark no GitHub:

https://github.com/marcelositr/daymark/issues

Para informações gerais sobre o projeto:

https://devnux.com.br/daymark

## Antes de abrir um bug

Se possível, informe:

- versão do Daymark
- plataforma: Linux ou Android
- o que você tentou fazer
- o que esperava acontecer
- o que aconteceu
- passos para reproduzir

Não publique sua senha mestra, arquivos privados do Journal, Backup completo, keystore Android ou outros segredos.

## Vulnerabilidades de segurança

Não use uma Issue pública para divulgar detalhes que possam expor uma vulnerabilidade antes de existir correção.

Siga a orientação de segurança indicada pelo repositório para contato responsável.

## Privacidade

O Daymark é local-first e offline-first.

O Journal fica no armazenamento local do aplicativo e usa banco de dados criptografado. Não é necessário criar conta para usar o produto.

## O que não deve ser confundido com criptografia

- a preferência de aparência é um ajuste local do dispositivo
- um **Open Export** é texto puro
- arquivos copiados para fora do Daymark passam a depender da proteção do local onde você os salvou

Para uma cópia protegida e restaurável dentro do Daymark, use [[Backup e Restore|Backup-e-Restore]].

## Bloqueio do Journal

O Daymark oferece:

- bloqueio manual
- bloqueio automático por inatividade
- bloqueio quando o sistema/dispositivo informa uma sessão protegida

Mesmo assim, a segurança final também depende da proteção do próprio computador ou telefone.
